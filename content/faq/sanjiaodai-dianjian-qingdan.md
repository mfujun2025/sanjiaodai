## 一、为什么需要成文的点检表

三角带维护的现状通常是：**出问题才处理**。带来的后果是失效总是在最不方便的时候发生（生产高峰、夜班、无人值守），而且因为缺少记录，无法判断是选型问题还是维护问题。

一份点检表的作用是把判断前置，并且**积累可分析的数据**。

## 二、日检项目（每班或每日）

操作者可在开机、运行、停机时顺手完成，不需工具：

- [ ] 开机时听有无**异常噪声**（尖叫、啪啪声、撞击声）
- [ ] 嗅有无**焦糊味**（打滑生热的信号）
- [ ] 观察带体运行轨迹是否**平顺、无晃动、无翻带**
- [ ] 目视带体有无**明显裂纹、掉块、断股**
- [ ] 确认**防护罩完好**（安全项，必须项）

**异常处理原则**：发现尖叫、焦糊味、翻带，**立即停机检查**，不要"先干完这一班"。

## 三、周检项目（每周或每 100 小时）

需要简单工具，可由维修人员完成：

- [ ] 用**挠度法**检查张紧力（跨度中央按压，每 100mm 跨度沉 1.5~2mm 为宜）
- [ ] 多根使用时，**逐根对比张紧力**是否一致
- [ ] 确认**根数是否齐全**（有无断根未发现）
- [ ] 检查带体**侧面是否发亮发硬**（打滑史）
- [ ] 检查带体**花纹/印字是否被磨平**（磨损程度参考）
- [ ] 检查**电机底座螺栓**是否松动（松动会改变中心距）

## 四、月检项目（每月或每 500 小时）

需要卡尺、直尺、塞尺：

- [ ] 用**卡尺量顶宽**，与新品比对，评估磨损程度
- [ ] 用**直尺/拉线/激光**复核两带轮**对中状态**
- [ ] 用**塞尺**测带轮端面平行度偏差
- [ ] 用**槽形样板或卡尺量带轮槽宽**，判断是否超差
- [ ] 检查**带轮槽底有无磨痕**（有则说明带底已触底，配合失配）
- [ ] 检查**带轮径向/端面跳动**（百分表）
- [ ] 清理带轮槽内积尘、异物（尤其切边齿形带的齿槽）

## 五、年度检查（每年或大修期）

- [ ] 全面检测带轮槽形与跳动，评估是否**成套更换带轮**
- [ ] 复核**传动设计参数**是否仍与实际工况匹配（载荷是否变化、是否换了电机）
- [ ] 复核**选型**是否仍然合适（用实际失效记录反推）
- [ ] 检查**库存储存条件**，清理超期备件
- [ ] 复盘**更换台账**，分析失效模式分布

## 六、更换决策表

出现以下**任一**情况，应安排更换：

| 判据 | 检查方法 | 说明 |
|---|---|---|
| 带体裂纹、缺口、掉块 | 目视 + 手感 | 结构性损伤，不可继续使用 |
| 侧面发亮、发硬 | 目视 | 打滑导致胶料老化 |
| 带底已触及带轮槽底 | 目视槽底是否有带体磨痕 | 说明带已磨损变窄，传递能力大幅下降 |
| 张紧调到极限仍打滑 | 调整 + 试运行 | 带与轮已失配 |
| 一组带中已有断裂 | 目视清点 | **整组更换** |
| 达到厂家建议最长年限 | 查台账 | 即使外观完好 |
| 带轮槽宽超差 | 量槽宽 | **先换轮**，否则新带很快失效 |

**整组更换原则**：一组带中有一根断裂，剩余各根已承受不均匀载荷、发生不同程度伸长，**只补一根会再次形成长短不一**。

## 七、更换台账模板

建议每台设备一张表，长期记录：

| 日期 | 设备编号 | 带型号与长度 | 根数 | 上次更换日期 | 运行小时 | 失效形式 | 更换原因 | 备注 |
|---|---|---|---|---|---|---|---|---|
| 2026-03-12 | F-101 | SPB2500Lw | 4 | 2025-11-08 | 3200 | 打滑发亮 | 张紧调至极限仍打滑 | 已同时更换带轮 |

**台账的价值在于趋势**：

- 连续几次都是"打滑发亮" → 检查张紧管理与工况系数是否偏小
- 连续几次都是"横向断裂" → 检查过载与启动方式
- 不同设备寿命差异大 → 对比安装质量与对中状态
- 同一位置反复坏 → 对应带轮槽有问题

**没有台账，这些判断都只能靠猜。**

## 八、常见失效现象速查

| 现象 | 首要排查方向 |
|---|---|
| 运行尖叫、焦糊味 | **张紧不足**（打滑） |
| 轴承温度偏高 | **张紧过大** |
| 带体侧面发亮发硬 | 长期打滑 |
| 带体横向整齐断裂 | 过载、冲击、疲劳 |
| 带体纵向撕裂、包布翻卷 | **带轮不对中**、撬带损伤 |
| 带底/齿根开裂（均匀分布） | 小带轮过小、高温、老化 |
| 带底/齿根开裂（集中一段） | 该段对应带轮槽问题 |
| 带体翻出槽 | 严重不对中、张紧过松、槽角不匹配 |
| 齿槽积满黑垢 | 粉尘环境，考虑改用包布带 |
| 多根接连断裂 | 未配组、长度不一致 |

## 九、安全项（不可省略）

- [ ] 拆装检修前**断电并挂牌上锁（LOTO）**
- [ ] 等设备**完全停止**后再操作
- [ ] **禁止运行中**检查、调张力、清理
- [ ] 护罩拆下后**必须复装**再试机
- [ ] **严禁用撬棍、螺丝刀**装带
- [ ] 备好合适的工具，不用替代工具勉强操作

安全上省的事，代价通常是事故。

## 十、从点检到改进的闭环

点检表只有在**闭环**时才有价值：

```
点检发现异常 → 记录 → 处理 → 记录处理方式
     ↓
积累 3~6 个月 → 分析失效模式分布
     ↓
判断是选型问题 / 安装问题 / 工况变化 / 配套件老化
     ↓
针对性改进（改选型 / 改流程 / 换带轮 / 改润滑方式）
```

**如果只做点检不分析，等于只是在记录故障，没有解决问题。** 本文所述判据为经验性整理，具体数值请以设备技术文件和现行标准为准。
