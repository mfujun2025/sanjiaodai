## 一、为什么只报型号会吃亏

"B 型 1800，多少钱一根？"——这句话能得到一个价格，但得不到你需要的东西。

同一句询价，供应商可以给你：天然橡胶包布带、聚酯线绳、Li 基准、无抗静电、按单根发货。也可以给你：氯丁橡胶切边带、芳纶线绳、Lw 基准、抗静电、按组配货带组号。**两者成本可能差 50% 以上，寿命差一倍以上，但报价单上都是"B 型三角带"。**

下面这十个问题，能把询价变成可比较、可核验的技术采购。

## 二、十个问题

### 1. 胶料是什么？适用温度范围多少？

**要问的理由**：胶料决定耐温耐油上限，是寿命的第一变量。

**合格回答**：明确胶料名称（氯丁橡胶 / EPDM / NBR / 天然橡胶）+ **书面标称的连续工作温度范围**。

**不接受**："耐高温""耐油耐磨"这类形容词，或者只有峰值温度没有连续温度。

### 2. 骨架（强力层）是什么材料？

**要问的理由**：骨架决定额定承载能力和抗伸长性，是"同型号不同档次"的主要差别来源。

**合格回答**：聚酯线绳 / 芳纶线绳 / 钢丝绳，并说明对应的额定承载等级。

**追问**：如果是芳纶，能否提供该型号的额定功率表？

### 3. 是包布带还是切边（齿形）带？

**要问的理由**：两者的传动能力、柔性、抗粉尘能力都不同，价格也不同。

**合格回答**：明确包布或切边，若是切边说明是否双面齿。

**注意**：粉尘大的场合应选包布；小带轮高转速场合切边更好。

### 4. 长度是按哪个基准标的？Li 还是 Lw？

**要问的理由**：**这是最容易出错的一项**。同一个"1800"，标 Li 和标 Lw 的实物长度可以差几十毫米，直接影响能不能装上。

**合格回答**：明确 Li / Lw / Ld / La，并能提供该型号 Li 与 Lw 的对应值。

**不接受**："就是标准的 1800"。

### 5. 长度公差是多少？能按组配货吗？

**要问的理由**：多根并用时，长度不一致会导致载荷分配不均、接连断带。

**合格回答**：给出长度公差范围，承诺**按组供货并标注组号**，关键设备可提供组内偏差数据。

**追问**：如果我要 4 根，是不是同一批、同一组号？

### 6. 有额定功率表吗？

**要问的理由**：选型计算里的根数直接由这张表决定，不同厂家的表不一样。**没有表就无法做正确的选型核算**。

**合格回答**：提供该型号在各带轮直径、各转速下的单根额定功率数据。

**注意**：如果供应商只给"我们用多少年没问题"的口头经验，选型就变成了猜。

### 7. 有没有耐温 / 耐油 / 抗静电的实测数据？

**要问的理由**：防爆、粉尘等场合的抗静电要求属于**安全项**，口头说明不能作为依据。

**合格回答**：书面标称值，抗静电需提供**表面电阻测试数据**。

**不接受**："我们的带都抗静电"。

### 8. 有哪些认证或合规文件？

**要问的理由**：出口业务、特定行业客户审核会要求。

**合格回答**：相关体系认证、目标市场需要的环保合规声明（有害物质限值等）。

**务实建议**：有出口业务时，事先把目标市场的物质限值要求和需要哪些声明文件列清楚，在技术协议里写明。

### 9. 质保期与失效认定方式怎么定？

**要问的理由**：避免出问题时扯皮。

**合格回答**：明确的质保期（时间或运行小时数）、失效认定流程、需要提供哪些证据（断口照片、运行记录）。

**务实建议**：约定"如认定为产品缺陷，双方如何分担"，以及"批量到货抽检不合格如何处理"。

### 10. 到货时能否提供批次与长度核对数据？

**要问的理由**：可追溯。到货就能核对长度和组号是否与合同一致，不用等装上去才发现问题。

**合格回答**：随货提供批次号、长度规格、组号；接受到货抽检。

## 三、询价单模板要点

把上面十问整理成一段可直接复制的要求：

```
采购要求

1. 型号与截面：B 型（普通 V 带）
2. 长度：节线长度 Lw 1800 mm（请明确贵司标注基准，如为 Li 请换算说明）
3. 数量：一组 4 根，需按组配货并提供组号
4. 长度公差：（请贵司提供具体范围）
5. 结构：包布式
6. 胶料：氯丁橡胶，连续工作温度范围？请提供标称值
7. 骨架：聚酯线绳（如有高等级选项请一并报价说明）
8. 抗静电：需要，请提供表面电阻测试数据
9. 请提供该型号额定功率表
10. 请提供质保期、失效认定流程、到货批次与长度核对数据

使用工况：设备类型 ____，电机功率 ____ kW，主动轮转速 ____ r/min，
        从动轮转速 ____ r/min，每日运行 ____ 小时，环境温度 ____℃，
        是否有油污/粉尘（是/否）
```

**把工况写清楚这一步经常被省掉**，但它直接影响供应商的报价合理性和选型建议质量——工况不同的两根带，供应商的成本结构完全不同。

## 四、到货验收要点

| 检查项 | 方法 |
|---|---|
| 型号与长度标记 | 核对带体印字与合同一致 |
| 长度基准 | 确认标注是 Li 还是 Lw，与合同一致 |
| 组号 | 核对同组内组号是否相同 |
| 数量 | 实点根数 |
| 外观 | 无裂纹、缺口、包布翻卷、分层 |
| 截面尺寸 | 抽检顶宽、高度（与型号表比对） |
| 存储状态 | 见下节 |

## 五、储存注意事项

三角带是有保质期的橡胶制品，储存不当会提前老化：

- **避免阳光直射和紫外**，避免靠近产生臭氧的设备（电机、变压器）
- **避免油、溶剂、酸碱接触**
- **温度**：一般在 10~25℃ 较适宜，避免高温仓库
- **湿度**：不宜过高，避免结露
- **堆放**：**悬挂存放**（用大直径圆弧支撑）或平放，**不要小半径折叠、不要重压**
- **先进先出**：库存管理上按批次先进先出，避免长期积压
- **储存期限**：长期库存（通常超过一到两年量级）需重新评估，具体以厂家建议为准

**现场常见错误**：把备件带折起来塞在工具箱里。折痕处的线绳会受损，装上去以后从折痕处开始坏。

## 六、小结

| 核心原则 | 说明 |
|---|---|
| 把参数写全 | 型号 + 材质 + 骨架 + 结构 + **长度基准**，缺一项就可能买错 |
| 要数据不要形容词 | 耐温耐油抗静电必须有书面标称值 |
| 配组必须明确 | 多根使用时不配组，等于埋了个定时故障 |
| 工况要说清 | 供应商才能给出合理选型建议 |
| 建立到货验收 | 型号、基准、组号、外观、尺寸 |
| 储存要规范 | 防紫外、防油、防折叠、先进先出 |

采购的功夫花在询价阶段，比花在售后扯皮阶段划算得多。
