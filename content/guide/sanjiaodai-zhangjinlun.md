很多设备传动出问题，不是因为带选错了，而是因为**包角不够或者中心距没法调**。这时候最直接的解决方案是在带内侧加装一个**张紧轮**（idler pulley）。张紧轮不是"随便找个轮子压上去"那么简单——压错位置、直径选小、轴承不耐用，都会让情况比原来更糟。

这篇文章把张紧轮一次讲清：它到底起什么作用、应该压在松边还是紧边、直径怎么选、什么时候该用自动张紧轮，以及安装时最容易踩的三个坑。

---

## 一、张紧轮是什么：它在三角带传动里的角色

张紧轮是一个**不参与传动的空转轮**，只起两个作用：**增大包角**和**维持张紧力**。它自己不被电机驱动，也不向任何设备输出扭矩，纯粹靠压在带体上改变带的运行轨迹。

| 作用 | 说明 | 对应的典型场景 |
|---|---|---|
| **增大包角** | 压在松边内侧时，把带子往里顶，让小带轮接触弧变长 | 中心距固定、包角算出来不足 120° |
| **维持张紧力** | 靠弹簧/螺纹机构持续压紧，补偿带伸长后的松弛 | 中心距不可调、带子长期运行后变松 |
| **改变带的路径** | 让带绕过某个障碍或穿过特定空间 | 多轴传动、空间受限的布局 |

> 核心认知：张紧轮是**补救性组件**，不是首选方案。设计阶段尽量通过调整中心距和传动比来保证包角和张力，只有在结构不允许时再加装张紧轮。

## 二、张紧轮该压在哪一边：松边内侧是铁律

这是张紧轮安装最重要的一条规则，违反它等于白装：

**必须压在松边（松侧）的内侧。**

### 2.1 为什么必须在松边

三角带传动运行时，带的一侧受拉（紧边，张力大），另一侧松弛（松边，张力小）。

- **压在紧边上**：带被向外推离轮槽，楔紧效果被破坏，非但不能增张紧力，反而让带更容易跳出轮槽；同时紧边张力本身就大，张紧轮的轴承和支架会承受极大的附加载荷，很快失效。
- **压在松边上**：松边张力小，张紧轮需要的压紧力也小，轴承寿命长；并且向内侧压能让带更贴合小带轮，**增大有效包角**。

### 2.2 为什么必须在内侧（靠近带体凹面那一侧）

- **外侧压**：会把带从轮槽里"撬出来"，带体向外翻，楔紧失效，容易跳带。
- **内侧压**：把带推向小带轮，增加接触弧，包角变大，传动能力增强。

> 一句话记牢：**松边 + 内侧 = 包角增大；紧边或外侧 = 带跳出来。**

## 三、张紧轮直径怎么选：不能太小

张紧轮的直径直接决定它对带体的弯曲疲劳影响。这是选型最容易忽视的参数。

### 3.1 直径越小，对带的伤害越大

带绕在张紧轮上时会发生弯曲变形，轮径越小，弯曲越剧烈，带体的拉伸层和压缩层应变越大，**骨架层（线绳）疲劳加速**，寿命显著缩短。

### 3.2 工程经验下限

| 三角带截面 | 张紧轮最小推荐直径 |
|---|---|
| Y / Z / SPZ | ≥ 50 mm |
| A / SPA | ≥ 75 mm |
| B / SPB | ≥ 100 mm |
| C / SPC | ≥ 160 mm |
| D | ≥ 250 mm |
| E | ≥ 355 mm |

> 数值为工程经验参考，正式设计应查所采购厂家样本中的张紧轮最小直径表。张紧轮直径**至少取同规格小带轮最小直径的 0.5~0.7 倍**是一条实用的估算规则。

### 3.3 张紧轮直径对包角的放大效应

张紧轮直径本身也影响包角增量——直径越大，张紧轮与带的接触弧越长，包角提升越明显。在空间允许的情况下，**尽量选大一点的张紧轮**，既对带友好，又更有效。

## 四、张紧轮的两种主要类型

### 4.1 手动可调式（螺纹/偏心机构）

靠螺栓、螺母或偏心套手动调节压紧力，需要停机操作。

- **优点**：结构简单、成本低、调节直观
- **缺点**：不能自动补偿伸长，需要定期停机检查并重新拧紧
- **适用**：间歇运行设备、维护方便的场合、对成本敏感的场合

典型的调节方式是：张紧轮装在带有一个长孔的安装座上，松开螺栓后可以前后移动，调到合适位置后锁紧。

### 4.2 自动张紧轮（弹簧/液压阻尼）

内置弹簧或液压阻尼，能自动保持恒定的压紧力，随带子伸长自动补偿。

- **优点**：张紧力稳定、免维护周期长、能吸收振动
- **缺点**：成本高、结构复杂、更换时需要专用工具
- **适用**：连续运行设备、振动大的场合、汽车发动机附件传动、工况变化频繁的设备

汽车发动机上的附件传动（发电机、空调压缩机、水泵）几乎都用自动张紧轮，就是这个原因——这些设备长期高转速运行，带子伸长和振动都很大，手动张紧轮无法满足要求。

## 五、张紧轮安装位置的五条规则

### 规则一：压在松边内侧，越靠近小带轮越好

张紧轮距离小带轮越近，对小带轮包角的增大效果越显著。理想位置是**松边靠近小带轮出口处**，这样能最大幅度地"推"带进入小带轮。

### 规则二：不要让张紧轮和大带轮"抢位置"

张紧轮如果压得离大带轮太近，会减小大带轮的包角（虽然大轮包角本来就大，但过度靠近也会有负面影响）。**张紧轮应偏向小带轮一侧**，不要放在两轮正中间。

### 规则三：轴承座要有足够的强度和调节行程

张紧轮要靠螺栓或弹簧持续压住带子， bearing housing（轴承座）必须足够坚固，不能在使用中发生位移或变形。手动可调式还要预留足够的调节行程，以应对新带的初期伸长。

### 规则四：张紧轮表面要光滑，材质要与工况匹配

- 普通工况：铸铁或钢制即可
- 粉尘环境：表面应光滑不易积粉，或者改用包布带减少粉尘附着
- 腐蚀性环境：考虑不锈钢或表面处理（镀锌、发蓝）

### 规则五：定期检查轴承状态

张紧轮 bearings 是易损件，长期在偏载状态下运行容易过热、异响、卡死。一旦张紧轮轴承卡死，它就不再是"自由轮"，而会变成一个新的摩擦源，加速带的磨损。

## 六、什么情况下必须用张紧轮

不是所有传动都需要张紧轮。以下五种情况是张紧轮的**典型适应症**：

| 情况 | 症状 | 张紧轮怎么帮 |
|---|---|---|
| **中心距固定不可调** | 设备设计时轴距焊死，没有滑轨 | 加装张紧轮提供替代调节手段 |
| **包角计算不足 120°** | 小带轮包角算出来小于 120°，传动能力不够 | 压在松边内侧，有效增大包角 |
| **带子伸长后张紧力衰减** | 新带装好几个月后开始打滑，中心距已调到极限 | 自动张紧轮持续补偿伸长 |
| **垂直传动或大倾角传动** | 重力使带下垂脱离小带轮 | 张紧轮从下方托住松边，防止脱带 |
| **空间受限无法加大中心距** | 设备外壳限制了中心距的调整范围 | 用张紧轮替代增大中心距的方案 |

> 参考[三角带传动比与带轮包角计算](/guide/chuan-dong-bi-yu-dai-lun-bao-jiao-ji-suan/)了解包角计算公式，判断是否真的需要张紧轮。

## 七、张紧轮安装的五个常见错误

### 错误一：压在紧边上

后果：带被向外推离轮槽，打滑更严重，张紧轮轴承快速损坏。
改正：确认哪一边是松边（通常是从动轮出口到主动轮入口的那一侧），只压那边。

### 错误二：压在外侧（带体凸面）

后果：带被从轮槽里撬出来，楔紧失效，轻则跳带异响，重则整根带脱出。
改正：从带体凹面（朝向两轮中心的一面）压入。

### 错误三：张紧轮直径选得太小

后果：带绕小轮时弯曲疲劳加剧，带底开裂、线绳抽出，寿命缩短一半以上。
改正：按上表的最小直径标准选择，宁可大不可小。

### 错误四：张紧轮压得太靠近大带轮

后果：反而减小了小带轮的有效包角增量，得不偿失。
改正：张紧轮应靠近小带轮一侧安装。

### 错误五：用张紧轮代替定期维护和正确选型

后果：张紧轮只是补救手段，掩盖了原始设计的问题（如中心距不足、带型选小）。长期依赖张紧轮而不解决根本问题，设备故障会越来越频繁。
改正：新设计阶段优先调整中心距和传动比，把张紧轮作为最后手段。

## 八、张紧轮与相关组件的协同

### 8.1 与三角带打滑的关系

张紧力不足是打滑的首要原因（见[三角带打滑原因与处理](/guide/sanjiaodai-dahua-paicha/)）。张紧轮的核心价值就是**维持合适的张紧力**，但从根本上解决打滑还需要排查包角、带轮槽磨损、负载是否超限等其他因素。

### 8.2 与三角带跑偏的关系

张紧轮位置不对是导致跑偏的常见原因之一。如果张紧轮安装偏斜（轴线不平行于带轮轴线），带会在张紧轮处产生横向力，运行中逐渐跑偏（见[三角带跑偏原因与校正](/guide/sanjiaodai-paopian/)）。安装时要确保张紧轮轴线与带轮轴线严格平行。

### 8.3 与张紧力检测的关系

张紧轮装好后，需要用挠度法或张力计检测实际张紧力是否达标（见[三角带张紧力不足怎么办](/guide/sanjiaodai-zhangjinli-buzu/)）。自动张紧轮虽然能自动补偿，但也应定期确认弹簧力是否衰减、轴承是否灵活。

### 8.4 与带轮选择的关系

张紧轮本身也是一个"带轮"，它的槽型应与所用三角带截面匹配（A 型带配 A 型槽，B 型配 B 型槽）。未开槽的光面张紧轮也可用于某些场合，但会减小摩擦、增加打滑风险，需谨慎使用。更多带轮细节见[三角带带轮怎么配](/guide/sanjiaodai-dailun-xuanpei-jiancha/)。

## 九、采购张紧轮时要确认的信息

向供应商询价或采购张紧轮时，以下信息缺一不可：

```
1. 适用截面型号：A / B / C / SPB / SPC ...
2. 轮缘形式：光面 / 开槽（槽型需与带型一致）
3. 最小推荐直径：≥ [根据截面查上表]
4. 安装方式：固定式 / 可调式 / 自动弹簧式
5. 轴承类型：含润滑脂的密封轴承 / 需定期注油的开放轴承
6. 安装座形式：单孔 / 长孔（带调节行程）/ 偏心套
7. 材质：铸铁 HT200 / 钢制 / 不锈钢（视工况）
```

## 十、总结

| 要点 | 内容 |
|---|---|
| 核心作用 | 增大包角 + 维持张紧力（补救性组件，非首选） |
| 安装铁律 | **松边 + 内侧**，缺一不可 |
| 直径原则 | 越大越好，参考上表最小值，宁大勿小 |
| 类型选择 | 间歇/低成本选手动，连续/振动大选自动 |
| 五大禁忌 | 压紧边、压外侧、轮径过小、位置靠大轮、掩盖设计缺陷 |
| 日常维护 | 定期检查轴承状态、压紧力、轮轴平行度 |

张紧轮是一个看似简单但门道很多的组件。装对了，它是传动的" stabilizer"；装错了，它比没有还糟糕。**记住八个字：松边内侧，轮大位近**（靠近小带轮），其余的细节按上表的规范逐一核对，就能避开绝大多数问题。
