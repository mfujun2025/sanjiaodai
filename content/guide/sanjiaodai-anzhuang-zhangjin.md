## 一、安装质量决定一半寿命

同一批带子、同一台设备，安装手法不同，寿命可以差一倍以上。安装环节最容易出问题的四件事：

1. **两带轮不平行、不对中**
2. **用撬棍硬撬装带**，损伤骨架层
3. **张紧力凭手感**，过大或过小
4. **新带不做复紧**，运转几天后松垮打滑

下面逐项讲清楚。

## 二、带轮对中：最容易被忽略的一项

两轴不平行或带轮不在同一平面，会让带在运行中产生**侧向爬行和翻带**，同时侧面受力严重不均，一侧先磨穿。

### 检测方法

| 方法 | 做法 | 适用 |
|---|---|---|
| 直尺/拉线法 | 用长直尺或细线贴紧两带轮同一侧端面，观察间隙 | 中心距不大时的快速判断 |
| 激光对中仪 | 激光发射器固定在带轮端面，靶标在另一轮上读数 | 中心距大、精度要求高 |
| 塞尺法 | 在带轮端面与基准线之间用塞尺测间隙 | 现场常用，可量化 |

### 判定标准（工程经验）

- 端面**平行度偏差**：一般控制在每 100mm 中心距不超过 0.5mm 量级
- 端面**平面度偏差**：一般控制在 0.5 ~ 1mm 以内

具体数值应以设备技术文件和带的规格为准，**精度要求随带速升高而提高**——高转速下微小的不对中就会被放大成明显振动。

**实操建议**：调整时先松开电机底座的四个固定螺栓，用顶丝或调整垫片平移电机，边调边用直尺复核，锁紧后再复测一次（锁紧过程本身常会带来位移）。

## 三、装带：不许撬、不许卷

这是现场最常见的破坏性操作。正确与错误做法对比：

| 做法 | 说明 | 评价 |
|---|---|---|
| 松开张紧、缩短中心距后套上 | 从带轮槽直接放入，带体不受额外应力 | ✓ 唯一正确 |
| 用撬棍撬入槽内 | 强力撬压会**拉断芳纶/聚酯线绳**或造成局部层间剥离 | ✗ 严格禁止 |
| 用手硬卷入轮槽 | 侧边被槽壁刮伤，骨架层受剪切 | ✗ 禁止 |
| 用螺丝刀别入 | 割伤带体侧面 | ✗ 禁止 |

**为什么撬带特别致命**：三角带的强力层线绳是**直线方向承载**的，横向撬压会让线绳产生局部剪切和折痕。表面看不出问题，但运行后折痕处会成为疲劳裂纹的起点，寿命大幅缩短——而且这种损伤**往往在几百小时后就表现为异常断裂**，导致找不到原因。

**正确装带流程**：

1. 松开电机底座螺栓，把电机向主动轮方向移动，缩短中心距
2. 若滑轨行程不足，可能需要先拆下从动轮（注意别损坏轴和键）
3. **先套小带轮，再套大带轮**（小轮槽浅，好入）
4. 带体全部入槽后，向远离方向推动电机张紧
5. 调整平行度与中心距，锁紧螺栓，复测

## 四、张紧力：手感和数据

### 手感法（快速但不精确）

用拇指在中点用力下压，感受带体的弹性：

- **过松**：下压幅度很大、软塌、运行时明显抖动
- **过紧**：几乎按不动、硬实、运行时轴承温升明显
- **合适**：有明显弹性但需要一定力，下压后能回弹

### 挠度法（推荐，可量化）

在两轮跨度中央垂直施加规定的力 `F`，测量带下沉量：

```
每 100mm 跨度，下沉 1.5 ~ 2.0 mm 为合适
```

例：跨度 600mm → 中央施加规定力后下沉约 9~12mm。

施加力 `F` 的大小按截面和根数查厂家手册。这个方法至少能做到"每次调整有同一个判据"。

### 张力计法（精度最高）

使用带张力计，通过测量带的**固有振动频率**反算张紧力：

1. 松开张紧后把带装好
2. 沿槽方向拨动带体（像拨弦）使其振动
3. 用张力计对着带体测量振动频率
4. 与厂家给出的目标频率（或按公式换算的目标张力）比对

优点是不依赖手感、可记录可追溯，**适合批量设备和关键传动位**。缺点是仪器成本，且需要每根带单独测（多根带时要逐根检查一致性）。

### 过紧的危害常被低估

张紧力过大的后果：

- 带体和轴承承受额外径向载荷 → **轴承寿命显著下降**（这是最常见的连带损失）
- 带体内部发热加剧，胶料加速老化
- 骨架线绳长期高应力，疲劳寿命缩短
- 严重时直接拉断

**现场现象对照**：

| 现象 | 可能原因 |
|---|---|
| 运行中"吱吱"尖叫、有胶烧焦味 | 张紧**不足**导致打滑 |
| 轴承温度偏高、轴振动大 | 张紧**过大** |
| 带体侧面发亮、发硬 | 长期打滑摩擦所致 |
| 带体断面整齐断裂 | 载荷过大或强力层疲劳 |
| 带体沿长度方向撕裂/翻带 | 带轮不对中或槽壁损伤 |

## 五、新带必须复紧

这是最容易被省略、但收益最大的一步。

新带装上后，强力层线绳会经历一个**初始伸长期**，运行 24~48 小时后长度会明显增加，张紧力快速下降。如果不复紧：

- 带开始打滑 → 摩擦生热 → 胶料表面硬化发亮 → 摩擦系数进一步下降 → 打滑加剧
- 这个过程是**正反馈**，一旦进入就很难恢复，带子会提前报废

**正确做法**：

1. 新带装好后按标准张紧
2. 空载或轻载运行 30 分钟，检查有无异常
3. **运行 24~48 小时后停机复紧一次**
4. 之后按周期（如每月或每 500 小时）定期检查张紧力

**旧带张紧到极限仍打滑时，必须换新带。** 强行继续调紧会让带体截面变形失真、侧面与槽壁接触面变小，最终快速失效，同时轴承也受影响。

## 六、多根成组带的安装检查

一组多根带时，除了长度配组，安装阶段还要查：

1. **逐根测张紧力**：张力计逐根测，偏差过大的要重配
2. **检查根数是否齐全**：少一根会让其余各根载荷骤增
3. **确认所有带轮槽均对同一组带**：混用不同批次会让磨损速度分化
4. **带轮槽磨损一致性检查**：用槽形样板或量槽宽，磨损量相差大的槽会让对应位置的带提前失效

**一组带中有一根断裂时，建议整组更换。** 因为剩余各根已经承受了不均匀载荷、发生了不同程度的伸长，只补一根新带会再次形成长度不一致。

## 七、带轮槽的维护

带轮槽磨损是"新带装上很快就不行"的隐性原因。

| 检查项 | 方法 | 判定 |
|---|---|---|
| 槽宽 | 用槽形样板或卡尺量工作高度处的槽宽 | 超出该型号允许值上限即需更换或修复 |
| 槽底是否有带底磨痕 | 目视槽底 | 有磨痕说明带底已触底，配合尺寸已失配 |
| 槽侧壁粗糙度 | 目视 + 手感 | 有明显沟槽或毛刺需修整 |
| 带轮偏摆 | 百分表打表测径向/端面跳动 | 超差需校正或更换 |

**带轮槽修复**一般不可行（材料去除会改变槽形），实际以更换为主。

## 八、日常点检清单

建议纳入设备点检表：

- [ ] 带体是否有裂纹、缺口、侧面发亮发硬
- [ ] 张力是否在规定范围（张力计或挠度法）
- [ ] 有无异常噪声、啸叫、焦糊味
- [ ] 带轮防护罩是否完好（安全项，**旋转部件必须加防护罩**）
- [ ] 轴承温度是否异常
- [ ] 多根带是否根数齐全、张力一致
- [ ] 电机底座螺栓是否松动（松动会导致中心距变化，张紧力随即改变）

## 九、安全提示

三角带传动属于**旋转机械传动**，安装维护时必须：

- 停机并**执行断电挂牌上锁**（LOTO），防止误启动
- 等设备完全停止后再操作，禁止运行中检查或调张力
- 护罩拆下调整后**必须复装**再试机
- 撬棍、螺丝刀等工具不得用于装带

安全上的省事，代价通常是事故。这一条没有例外。

## 十、小结

| 环节 | 要点 |
|---|---|
| 对中 | 直尺/激光+塞尺，锁紧后复测 |
| 装带 | 松开张紧套入，**严禁撬压卷带** |
| 张紧 | 挠度法每 100mm 跨距沉 1.5~2mm，或张力计测频 |
| 复紧 | 新带运行 **24~48 小时必须复紧一次** |
| 配组 | 逐根测张力，一根断则整组换 |
| 带轮 | 槽宽、槽底磨痕、跳动定期查 |
| 安全 | 断电挂牌，护罩复装 |
