传动系统突然"咔"一声，带体从带轮上弹出来——维修工的第一反应往往是"是不是带松了"。但跳齿和脱槽的成因远比"张紧不够"复杂。跳齿主要见于同步带或带齿的传动系统，脱槽则是普通三角带完全脱离带轮槽位；两者看似相近，根因却大不相同。错误判断不仅修不好，还会让带轮和带体进一步损坏。这篇文章把跳齿和脱槽各自的结构机理、常见成因、现场排查步骤和预防要点一次讲清。

---

## 一、先分清楚：跳齿和脱槽是两种不同的故障

很多人把"跳齿"和"脱槽"混用，但在工程意义上它们属于不同类型的失效：

| 特征 | 跳齿（skipping / tooth jump） | 脱槽（coming off / belt run-off） |
|---|---|---|
| **常见于** | 同步带、齿形 V 带（如齿形切边带） | 普通三角带、窄 V 带 |
| **现象** | 带齿瞬间脱离带轮齿槽啮合，发出"咔哒"声；负载波动明显 | 带体整体从带轮槽中滑出，可能完全脱离 |
| **直接后果** | 齿面磨损、齿形破坏；同步传动丢步 | 带体侧面剧烈磨损；带体翻卷、断带 |
| **核心原因** | 张紧力不足、啮合齿数不够、冲击载荷 | 不对中、轮槽磨损、张紧不当、带体伸长 |

**一句话区分**：跳齿是"齿对不上齿"，脱槽是"带脱离了轮"。普通三角带没有齿，所以严格意义上不存在跳齿——它只会脱槽。但市场上有些带体带齿（齿形切边带），这类带在异常情况下也会出现类似跳齿的现象，本质上仍是轮槽配合问题。

以下讨论以普通三角带脱槽为主，同时补充同步带/齿形带跳齿的相关内容。

---

## 二、脱槽的六大成因

### 2.1 带轮不对中（最常见原因）

两带轮的轴线不平行，或端面不在同一平面，是脱槽的首要诱因。当带进入小轮时，如果轮槽侧壁与带体侧面不能全面贴合，带的运行轨迹会逐渐偏移，最终从较宽的一侧脱出。

判断方法：用直尺靠在两个带轮的端面上，检查是否齐平；或用拉线法测量两带轮中心的平行度偏差。偏差超过带宽的 1% 就应进行调整，见[三角带带轮怎么配：槽型、直径与磨损检查](/guide/sanjiaodai-dailun-xuanpei-jiancha/)。

### 2.2 带轮槽磨损过度

带轮槽长期使用后，槽壁会磨损变宽、槽角变大（标准槽角 34°~38°，磨损后可能达到 40° 以上）。槽变宽后，带体在槽中的定位能力下降，张紧力波动时就容易滑出。

> 检测要点：用槽形样板或卡尺量槽宽，对比新品规格；肉眼观察槽底有无明显磨痕。磨损严重的带轮应及时修整或更换。

### 2.3 张紧力不当

张紧力过小，带体在带轮上的压紧力不足，摩擦力不够，带在运转中容易被"甩"出槽外；张紧力过大则会使带体过度伸长，加速带轮轴承磨损，间接增加不对中风险。正确张紧力的检测方法，见[三角带安装与张紧：对中、初张力与复紧](/guide/sanjiaodai-anzhuang-zhangjin/)。

### 2.4 带体过度伸长或老化

三角带长期运行后，内部线绳拉伸、橡胶老化变硬，带体厚度变薄、宽度变窄。带变窄后与带轮槽的配合间隙增大，定位能力下降。此外，新旧带混装会导致各根带的伸长率不同，部分带受力过大、部分带松弛，松弛的带更容易脱槽，见[三角带多久换一次](/guide/sanjiaodai-genguan-zhouqi/)。

### 2.5 竖直传动或大倾角传动

竖直布置的传动系统中，带体自重会使其沿轴向下滑。单根带的这种趋势会被长度差异放大——某根带略长或略松，就更容易向下滑脱。这类工况下应考虑使用联组带（将多根带用织带连接，防止单根脱出），见[联组带与多根带配组：什么时候必须用、配组差怎么算](/guide/sanjiaodai-lianzu-dai-peizu/)。

### 2.6 冲击载荷与频繁启停

破碎机、压缩机、冲床等设备的周期性冲击载荷，会在瞬间产生远超额定扭矩的惯性力，这种冲击力会猛地把带从轮槽中"拽"出来。频繁启停则让带反复经历张紧-松弛的应力循环，加速带体松弛和轮槽磨损。

## 三、跳齿的三大成因（同步带/齿形带）

### 3.1 张紧力不足

同步带靠齿的啮合传力，但预紧力仍需要提供足够的摩擦力来吸收啮合误差和振动。张紧力不足时，齿面间的正压力下降，齿在承受冲击载荷的瞬间可能跳过一个齿距，这就是跳齿。

### 3.2 啮合齿数不足

同步带设计规范要求至少 **6 个齿同时啮合**（小轮齿数少时要求更高）。啮合齿数不足时，单个齿承受的载荷过大，容易发生齿面剪切破坏或整体跳齿。小带轮直径越小、中心距越短，啮合齿数越少，应通过[三角带选型计算](/guide/sanjiaodai-xuanxing-jisuan/)校核。

### 3.3 带轮齿形磨损或带齿磨损

同步带轮齿面和带齿面都是精密配合面。长期使用后，齿面磨损导致啮合间隙增大；带齿磨损（尤其是齿顶变平、齿侧出现阶梯状磨损）后，啮合精度下降，在扭矩波动时容易跳齿。一旦发现跳齿，**应成对更换带与带轮**——新带配旧轮会加速新带磨损。

## 四、现场排查六步法

遇到跳齿或脱槽，按以下步骤逐一排查，避免凭感觉换件：

### 第 1 步：停机检查带体状态

- 目视带体是否有裂纹、掉块、齿面磨损（齿形带）、侧面发亮发硬（打滑史）
- 对比新旧带长度：将新带与旧带并排放，观察有效长度差异
- 检查带体是否翻转（翻带）：带体侧面朝上或内侧外露，说明已经严重跑偏

### 第 2 步：检查带轮槽状态

- 用手摸槽壁：光滑发亮说明有打滑史，有明显磨痕说明磨损严重
- 用卡尺量槽宽和槽角：与新品规格对比
- 检查槽底：带底如果碰到槽底（无间隙），说明带已过度磨损或轮槽过深

### 第 3 步：复核两带轮对中

- 用直尺或拉线法测量两带轮端面是否齐平
- 测量两轴平行度：用百分表打端面跳动和径向跳动
- 偏差 > 1° 或端面错位 > 带宽 1% 需要校正

### 第 4 步：检查张紧力

- 用挠度法：在两带轮跨度中央按压带体，每 100mm 跨度下沉 1.5~2mm 为宜
- 有条件的用张力计（振动式）测量实际张力值
- 多根带传动时，逐根对比张力是否一致

### 第 5 步：检查工况历史

- 最近是否有更换带体？更换时是否混装了新旧带或不同品牌？
- 是否有设备改造（中心距变动、带轮更换）？
- 是否长期超负荷运行或有异常冲击载荷？

### 第 6 步：综合判断并处理

根据以上排查结果，对照下表决定处理方案：

| 排查结果 | 处理措施 |
|---|---|
| 带轮不对中 | 调整电机位置或加减垫片，重新对中 |
| 带轮槽磨损 | 更换带轮（仅打磨修复槽宽超差的轮） |
| 张紧力不足 | 重新张紧，按[安装张紧指南](/guide/sanjiaodai-anzhuang-zhangjin/)执行 |
| 带体过度伸长 | 成组更换全部带体（多根传动时），见[更换周期](/guide/sanjiaodai-genguan-zhouqi/) |
| 竖直传动脱槽 | 加装惰轮或改用联组带 |
| 冲击载荷导致 | 检查设备工况，考虑加装张紧轮或液力耦合器缓冲 |

## 五、预防脱槽跳齿的五个要点

### 5.1 安装时确保对中

新带安装或更换带轮后，**必须重新校核对中**。这是成本最低、效果最好的预防措施。对中不良是脱槽的首因，没有之一。

### 5.2 保持正确张紧力

新带运行 24~48 小时后必须复紧（[新带复紧方法](/guide/sanjiaodai-anzhuang-zhangjin/)），因为初期伸长量最大。之后按[点检清单](/faq/sanjiaodai-dianjian-qingdan/)定期检查张紧力。

### 5.3 同步更换整组带

多根带传动时，**严禁新旧混装**。即使只有一根损坏，也建议整组更换——新旧带的伸长率不同，新带受力过大、旧带松弛，松弛的那根最容易脱槽。

### 5.4 定期点检带轮槽

将带轮槽磨损检查纳入月度点检项目。槽宽超差或槽角变大的带轮应及时更换，不要等到带频繁脱槽才处理。

### 5.5 特殊工况采取额外措施

- 竖直传动：加装张紧轮或改用联组带
- 冲击载荷大的设备：选用齿形切边带（柔性好、抗冲击）或考虑加装飞轮缓冲
- 多尘环境：加防护罩，防止异物进入轮槽（防护罩也是[点检清单](/faq/sanjiaodai-dianjian-qingdan/)的必查项）

## 六、三个常见误区

**误区一：脱槽就是张紧力不够。**
张紧力不足只是原因之一。不对中、轮槽磨损、带体伸长这些因素同样甚至更常见。只加紧张紧而不解决对中问题，短期内可能不脱了，但带的侧面会异常磨损，寿命反而更短。

**误区二：跳齿只能用更紧的张紧力解决。**
同步带跳齿除了张紧力，还可能是啮合齿数不足或带轮/带齿磨损。张紧过度会急剧磨损轴承，适得其反。应先检查啮合齿数是否达标（≥6 齿），再判断是否需要更换带轮。

**误区三：脱槽后把带塞回去就能继续用。**
脱槽后的带体侧面往往已有明显磨损，继续运行会加速损坏，甚至断裂。应取出检查侧面磨损情况，磨损严重的必须更换，不要心存侥幸。

## 七、订货与备件建议

处理完本次故障后，为避免同类问题反复发生，建议在下次采购时注意：

```
优先选齿形切边带（高频/冲击工况）  → 减少脱槽倾向
多根传动必选联组带（竖直/大角度工况）→ 防止单根脱出
备件库保留同型号 +10% 长度的库存   → 应对中心距微调需求
```

具体型号和尺寸参数的查询，见[三角带规格速查](/guide/sanjiaodai-guige-zhuchaxun/)；不同材质（氯丁橡胶、EPDM、聚氨酯）的耐温/耐油/耐候特性，见[三角带材质怎么选](/basics/sanjiaodai-cailiao-xuanze/)。

## 八、常见问题（FAQ）

**Q1：普通三角带会跳齿吗？**
严格来说不会。普通三角带没有齿，只有脱槽（带脱离轮槽）和打滑（带在轮槽内滑动但不脱离）两种失效。市场上偶有"齿形三角带"（在带体侧面开横向齿的切边带），这类带理论上可能产生类似跳齿的现象，但本质仍是轮槽配合问题，不是真正的齿啮合跳齿。

**Q2：脱槽和跑偏是一回事吗？**
不是一回事。跑偏是带在运行中逐渐偏向一侧的趋势（[三角带跑偏怎么办](/guide/sanjiaodai-paopian/)），脱槽是跑偏发展到极端的后果——带完全脱离轮槽。跑偏及时处理可以避免脱槽。

**Q3：一根带脱槽了，其他几根要一起换吗？**
建议整组更换。多根带传动中，一根脱槽通常意味着这根的张紧力偏松或受力异常，其他带也可能处于不均衡状态。继续混用新旧带会加速新带的早期失效。

**Q4：脱槽后带还能用吗？**
取出后立即检查带体侧面。如果侧面有明显磨痕、发亮、起毛或台阶状磨损，说明已经受损，不应继续使用。轻微脱槽且侧面完好的带，可在排除故障原因后短期使用，但建议列入下次更换计划。

**Q5：同步带跳齿会损坏设备吗？**
会。跳齿会导致同步传动"丢步"，从动设备的位置或转速瞬间失准；反复跳齿会快速磨损齿面，最终导致带体断裂。一旦发现跳齿，应立即停机检查，不要带病运行。

**Q6：张紧轮能防止脱槽吗？**
张紧轮可以维持张紧力、增大包角，间接降低脱槽风险。但如果根本原因是带轮不对中或轮槽磨损，仅加张紧轮治标不治本。张紧轮的选型与安装位置见[三角带张紧轮指南](/guide/sanjiaodai-zhangjinlun/)。

## 九、小结

| 要点 | 内容 |
|---|---|
| 核心区别 | 跳齿=齿啮合失效（同步带/齿形带）；脱槽=带脱离轮槽（普通三角带） |
| 首要原因 | 带轮不对中；其次是轮槽磨损和张紧力不当 |
| 排查顺序 | 带体状态→带轮槽→对中→张紧力→工况历史→综合处理 |
| 关键预防 | 安装必对中、新带 48h 复紧、多根必整组换、定期点检轮槽 |
| 危险信号 | 运行中"咔哒"声、带体完全脱离轮槽、同步传动丢步 |
| 处理原则 | 找出根因再处理，不要只加张紧力或只换带 |

脱槽和跳齿都不是突发性无兆头的故障，绝大多数都有前兆：异响、振动加剧、带体侧面异常磨损。把这些信号纳入日常[点检清单](/faq/sanjiaodai-dianjian-qingdan/)，就能在故障发生前完成干预，避免非计划停机。更详细的故障诊断参考[三角带失效形式与原因排查](/guide/sanjiaodai-shibai-fenxi/)和[三角带打滑排查](/guide/sanjiaodai-dahua-paicha/)。

> 说明：本文所述跳齿、脱槽的成因分析与排查方法基于**工程实践与行业通行经验**，不同设备制造商对张紧力、对中精度、啮合齿数的具体要求可能存在差异。实际处理时应以设备厂家技术文件、现行国家标准及传动系统供应商数据为准；涉及高压、高温或大型旋转设备的检修作业，应由具备资质的人员按安全规程执行。
