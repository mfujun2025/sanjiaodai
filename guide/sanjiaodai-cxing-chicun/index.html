C型三角带尺寸规格：截面参数、配轮与长度选择

选型与安装维护 发布于 2026-10-19 作者：三角带行业资讯编辑部 约 13 分钟阅读

设备上一根带断了，卡尺一量顶宽 22mm、高度 14mm——这是 C 型。但现场栽跟头的，往往是另外两种情况：把磨损后的 B 型误判成 C 型，或者把 C 型和顶宽同样 22mm 的 SPC 搞混。型号认错，装上去不是打滑就是烧带，几天就得拆下来返工。

C 型是国标普通 V 带里的中大功率截面，空压机、破碎机、搅拌机、输送机、中型风机上到处都是。这篇文章把 C 型的尺寸规格一次讲清：截面参数是多少、怎么量怎么判、配什么带轮、长度怎么选、型号怎么读。

一、C 型是什么：国标普通 V 带体系里的中大主力

国内普通 V 带按截面从大到小分为 Y、Z、A、B、C、D、E 七个型号（GB/T 1171 体系，国内基准制，长度以内周长 Li 标注）。C 型处在中间位置：比 A、B 大，比 D、E 小，是中大功率传动的核心截面。

型号 顶宽 b (mm) 节宽 bp (mm) 高度 h (mm) 参考适用功率
A 13 11 8 0.6 ~ 5 kW
B 17 14 11 1 ~ 15 kW
C 22 19 14 4 ~ 30 kW
D 32 30 19 15 ~ 80 kW

表中尺寸为标准普通 V 带截面参数，功率区间为工程参考范围，正式选型请以三角带选型计算和厂家样本为准。

C 型的"身材比例"：高宽比约 14/22 ≈ 0.64，和 A、B 型接近，都属于"扁梯形"的普通 V 带家族。它比 B 型宽 5mm、高 3mm，承载能力跟着上一个台阶；但比窄 V 带的 SPC 矮一截，这是现场区分两者的钥匙，第四节细说。

二、C 型三角带的核心尺寸参数

2.1 四个必须记住的数

参数 数值 说明
顶宽 b 22 mm 带体最宽处宽度，梯形上底，现场唯一能直接量的宽度
节宽 bp 19 mm 带中性层处的宽度，带轮槽按它设计，实物上量不到
高度 h 14 mm 顶宽到带底的总高度，判断槽深匹配用
楔角 40° 自由状态下的截面角度，装进轮槽弯曲后会变小

顶宽和节宽为什么差 3mm：和 A、B 型一样，C 型的强力层（线绳）走在中性层，带轮槽的工作尺寸按节宽 19mm 设计。买带时说"22 的带"指的是顶宽，配轮时供应商按节宽 19mm 开槽。更细的区别见三角带顶宽、节宽、高度的区别与识别。

2.2 尺寸会"变"：磨损与公差的现实

  • 新带顶宽就是 22mm 左右，正公差一般不超过零点几毫米；
  • 旧带顶宽会变小：侧面磨掉一层后，量出来可能是 21~21.5mm，不能因此判成 B 型；
  • 包布老化的带顶宽会偏大：包布层吸水膨胀或厚硬化后，量出来比 22mm 大，容易误判成 D 型；
  • 非标产品顶宽不准：小厂产品可能做到 20mm 或 23mm，单靠顶宽定型号本身就有风险。

所以工程上的严谨做法是顶宽 + 高度组合判定：22mm 顶宽配 14mm 高度才是 C 型；B 型是 17 + 11，D 型是 32 + 19，SPC 是 22 + 18。

三、怎么判断一根带是不是 C 型：现场五步法

拿到一根没有印字的旧带，按这个顺序判：

  1. 先找印字。正规产品带体侧面印有型号、长度甚至批次，这是最可靠的依据。印字磨没了才走测量路线。
  2. 量顶宽。用卡尺在避开磨损段的位置量，取最大值附近读数。22mm 左右 → 锁定 C 或 SPC。
  3. 量高度。14mm → 普通 V 带 C 型；同样 22mm 顶宽但高度约 18mm → 窄 V 带 SPC。高度是区分普通带和窄带的钥匙，C 与 SPC 顶宽几乎相同，只有高度差得出来。
  4. 对照带轮槽。用槽形样板比对，或量槽的顶宽与深度，与三角带规格速查表对照。槽的"胖瘦"直接说明该配普通带还是窄带。
  5. 仍不确定时，量带轮外径和中心距，反推所需节线长度，连同旧带照片一起发给供应商核算——比自己猜更稳。

最容易翻车的一步：只看顶宽 22mm 就认定 C 型。SPC 是欧制窄 V 带，顶宽同样 22mm，高度却是 18mm，比 C 型高 4mm。卡尺只量宽度必然分错，必须补量高度。两者槽深不同、承载能力不同、完全不能互换。详见第四节。

四、C 型与"邻居们"的区分表

现场真正要区分的不是全部七个型号，而是 C 型周围这几个"长得像"的：

容易混淆 C 型 对方 区分要点
C vs B 顶宽 22 / 高 14 B：顶宽 17 / 高 11 顶宽差 5mm，高度差 3mm，一眼可分
C vs D 顶宽 22 / 高 14 D：顶宽 32 / 高 19 D 明显更宽更厚，差出一个档
C vs SPC 顶宽 22 / 高 14 SPC：顶宽 22 / 高 18 顶宽几乎相同，靠高度差 4mm 区分，必须补量高度
C vs 5V 顶宽 22 / 高 14 5V：美制，对应 C 型区间 美制带体印字为英制，C 带体印字为公制

C 型和 SPC 为什么必须分清：SPC 是欧制窄 V 带，顶宽 22mm 与 C 型相同，高度约 18mm。SPC 比 C 型窄而高，同样节宽下承载能力更强，但槽深是按 18mm 设计的。C 装 SPC 槽会悬在槽里楔不紧，SPC 装 C 槽则直接触底、侧面没有接触——两种错装都是打滑或早期损坏。两套体系的完整对照见三角带型号体系对照：国标、欧制、美制，普通带与窄带的性能差异见普通V带与窄V带对比。

五、C 型配什么带轮：槽型、槽角与最小直径

C 型带必须配 C 型槽的带轮。三个关键数字：

5.1 槽角随直径变化

带体楔角标注 40°，那是自由状态的值。带绕上轮槽弯曲后楔角会变小，所以小直径带轮的槽角要做得更小：

C 型带轮基准直径 推荐槽角
200 ~ 250 mm 34°
250 ~ 315 mm 36°
> 315 mm 38°

数值为行业常见推荐值，不同来源略有差异，选型以现行标准和带轮供应商样本为准。反过来也成立：如果小带轮的槽角量出来是 38° 以上，说明槽壁已被磨开，该换轮了。

5.2 小带轮直径不能低于下限

截面 小带轮最小节圆直径（参考）
A 75 ~ 90 mm
B 125 ~ 140 mm
C 200 ~ 224 mm
SPC 224 ~ 250 mm

C 型小带轮低于约 200mm 时，带体反复大角度弯曲，骨架层疲劳急剧加速——表现为带底均匀开裂，现场常误判为"带子质量不好"。原设备如果小轮只有 180mm 左右还硬上 C 型，等于花钱买短命。

5.3 下单带轮说清四件事

  1. 槽型与槽数："C 型 × 3 槽"（一台设备两根以上并联传动时按实际槽数）
  2. 基准直径：是节圆直径，不是外径，也不是"几寸"
  3. 轴孔与键槽尺寸：轴径、键宽 × 键高
  4. 配合形式：直孔 + 键，还是锥套式（锥套型号）

更多带轮细节与磨损检查方法，见三角带带轮怎么配：槽型、直径与磨损检查。

六、C 型的长度与型号标注

6.1 型号怎么读

国内普通 V 带长度按内周长 Li 标注，格式为「截面型号 + 长度数字 + Li」：

  • C2000Li = C 型截面，内周长 2000mm
  • C3550Li = C 型截面，内周长 3550mm

注意：标称 2000 是内周长，不是外周长。皮带尺绕外圈量出来的数会偏大（差值约 2 × 高度 ≈ 28mm 以上），直接按外圈读数下单会买长。带体印字怎么看、Li/Lw/Ld 三种基准的区别，见三角带型号命名规则解读。

6.2 常见长度档位

C 型常见档位大致覆盖 1250 ~ 9000mm+，市场上较普遍的规格有：

1250 / 1400 / 1600 / 1800 / 2000 /
2240 / 2500 / 2800 / 3150 / 3550 / 4000 / 4500 /
5000 / 5600 / 6300 / 7100 / 8000 / 9000 mm

具体可供规格因厂家而异，边界档位和加长规格需查供应商样本。换带优先抄旧带印字；印字磨掉时，按旧带测量与配带三步法操作，或量准带轮外径与中心距反推。

6.3 长度选不对的两种后果

  • 买长了：张紧后中心距被顶满，带体预应力过大，轴承负荷增加，带早期疲劳；
  • 买短了：张紧量不够，初张力不足，24~48 小时伸长后立刻打滑。

七、C 型适合什么工况，什么时候该换型号

7.1 C 型的主场

  • 中大功率传动：参考适用功率约 4 ~ 30 kW，覆盖大多数空压机、破碎机、搅拌机、输送机、中型风机；
  • 中低转速、中大载荷的场合，与 C 型截面的能力区间最匹配；
  • B 型升级场景：原设备用多根 B 型带，功率需求提升或根数超过 3~4 根时，换 2 根 C 型常能简化传动结构。

行业工况差异对带寿命的影响，有时比型号选择更大，选型前建议读不同行业三角带选型对照。

7.2 这三个信号出现，考虑升级型号

信号 方向
计算功率超出 C 型能力，或多根带仍打滑 升级 D 型 / 8V
空间紧张、带轮直径被限得很小 考虑窄 V 带（SPC，同节宽下功率更高）
高速、要求传动平稳低噪 窄 V 带（SPC）或多楔带方向评估

注意：换截面 = 换轮槽，不是只换带。老设备从 C 型改 D 型或 SPC，带轮要同步换，改完必须重算包角和带速。

八、采购下单怎么写才不出错

把一根 C 型带买对，订单上要出现四样信息：

C2000Li（截面型号 + 内周长 + 基准）  ×  数量
是否包布带 / 切边带（工况有粉尘或油污时必填）
使用工况简述（连续/间歇、环境、载荷性质）
  • 只写"C 型带子，两米"——基准不明、规格不明，供应商只能按最低成本猜；
  • 有粉尘、油污工况要说明：包布带耐磨防尘，切边带效率高但怕粉尘，选错寿命差一倍；
  • 价格与规格的对照关系，参考三角带价格多少钱一根；到货验收看三角带质量怎么判断。

九、常见问题（FAQ）

Q1：C 型三角带的标准尺寸到底是多少？ 顶宽 22mm、节宽 19mm、高度 14mm、楔角 40°。现场能直接量的只有顶宽和高度，节宽在带内部量不到，是带轮槽的设计基准。

Q2：量出来顶宽 21.5mm，是 C 型还是磨损前的 B 型？ 大概率是磨损后的 C 型。B 型新带顶宽才 17mm，即使全新也不会超过 17.5mm；磨损后只会变小。结合高度（14mm 左右）和带轮槽一起判更稳。

Q3：C 型带能配 SPC 的轮吗？ 不能。两者顶宽几乎相同（都约 22mm），但高度差 4mm（C 型 14mm，SPC 约 18mm），槽深设计不同。C 装 SPC 槽会楔不紧，SPC 装 C 槽会触底、侧面没有接触——两种都是打滑或早期损坏。两套体系的完整对照见三角带型号体系对照：国标、欧制、美制。

Q4：C2000 和 C2000Li 是一回事吗？ 是同一个规格的两种写法，都指 C 型、内周长 2000mm。国内普通 V 带基准制用 Li 标注；欧制 SP 系列用 Lw（节线长度），同名数字对应的实际长度不同。

Q5：C 型带一般能用多久？ 没有统一答案，取决于负载、转速、环境和对中状态。平稳工况下按年计，粉尘重载可能几个月。该换的信号和整组更换原则，见三角带更换周期与换带作业。

Q6：多根 C 型带并联，能一根一根换吗？ 不建议。新带和旧带伸长量不同，张紧后受力不均，新带很快过载。应整组更换，配组差控制原则见联组带与多根带配组。

十、小结

要点 内容
C 型尺寸 顶宽 22 / 节宽 19 / 高度 14 / 楔角 40°（国标普通 V 带）
现场判定 顶宽 + 高度组合判定；C 与 SPC 顶宽几乎相同，靠高度差 4mm 区分
易混对象 B（小一号）、D（大一号）、SPC（同宽不同高）
配轮三要素 C 型槽、槽角 34°/36°/38° 随直径变化、小轮 ≥200~224mm
长度标注 内周长 Li，C2000Li = 内周 2000mm，别拿外圈读数下单
换型号信号 功率超限 → D/8V；空间受限 → SPC；换截面必须换轮

C 型是普通 V 带里"功率够大、尺寸不夸张"的中大截面，尺寸规则一句话：顶宽 22、高度 14，配 C 槽，长度认 Li。把这几个数记牢，配带配轮现场就不会再靠猜。更完整的选型链路，从三角带选型计算实操开始看。
